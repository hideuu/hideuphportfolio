Gwynth's Printing Online Ordering

An online ordering system for a local print shop. Customers browse the catalog, upload design files, and place orders, while admins manage orders, messages, and reviews.

PHP MySQL JavaScript HTML/CSS
Live Demo (front-end only) Source Code

About

Gwynth's Printing needed a way to take orders online instead of through chat messages. The site lets customers browse printing services, upload their design files, choose a payment method, and leave reviews. Behind it, an admin panel handles incoming orders, contact messages, and review approval.

What I learned

  • Designing a MySQL schema for orders, reviews, and messages, and writing the SQL to connect them
  • Handling file uploads safely in PHP
  • Building a simple admin panel with approve/reject flows
  • Running and testing a full PHP stack locally with XAMPP
